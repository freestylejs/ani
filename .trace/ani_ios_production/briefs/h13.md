## Prerequisite 2 — essential purpose

A held element is the user's finger on the screen. Its drawn origin must equal
`take point + offset` every frame under scroll, a live ancestor scale, sticky headers and re-layout;
the drop must continue with the release velocity exactly once. Descendants ride one common
displacement `h(t)` and keep their own residuals. No jump, no double-counted velocity, no wrong
frame, no leaked hold.

## Prerequisite 3 — task boundary

### Thesis: what you build

1. **Public surface** (§5.10): `LayoutDriveVector`, `LayoutDriveState`, `LayoutDriveHandle`,
   `LayoutDrive`; export from the layout entry. React `useLayoutDrive()` routes to the live scope
   that owns the element; `take` with no owner throws `ANI_INVALID_OPTIONS`.
2. **State machine**: `take`, `move`, `release`, `cancel`; preconditions (registered/connected/same
   document/`raf`/not held/no ancestor or descendant hold/supported geometry); terminal idempotence;
   non-finite input throws without state change; `take` under runtime `'snap'` returns an
   `invalidated` handle with `runtime-disabled`.
3. **Held read and pose**: each frame, in the clock's read phase before writes, read the held
   element's rect, divide out the last written pose to recover the presented layout box, and solve
   the pose that puts the drawn origin at `H` through current parent maps. Count the read in
   `stats`.
4. **Descendants**: one inherited displacement `h(t)`; at take, re-plan running descendants as
   residuals from `(drawn − h, drawn velocity − ḣ)`; at release, the release velocity enters only
   through the held node's origin track; every descendant is drawn at `residual + h`; a flush while
   held/landing replans residuals from measured `(B − h, v − ḣ)`.
5. **Held under hostile conditions**: scroll while held, ancestor scale 1→2, re-render while held,
   `layoutKey` change, removal, document change, dispose/finish/kill switch, failed support check →
   `invalidated` and the event's rule; reads stop.
6. **Reduced motion**: the hold is never interrupted by a policy change; at release `'jump'` lands
   at A with no motion, `maxDuration` clamps per §9.4, `'ignore'` plays full. A release with no
   layout change springs back to the slot.
7. **React**: `useLayoutDrive` in the adapter, StrictMode same-task detach/re-attach preserves a
   hold, no DOM ownership by React.
8. **Rows L-DRIVE-1..6** in Chromium and WebKit, plus React adapter tests. The rows must use the
   independent oracle where they make a frame/velocity claim; no tolerance weakening.
