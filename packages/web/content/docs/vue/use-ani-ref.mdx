---
title: useAniRef
description: A function ref and an initial style that bind an element to a timeline.
---

This composable binds one element to a timeline through `timeline.bind`. Styles are written by the core engine in the commit phase, changed declarations only, so Vue does not render per frame. DOM events are Vue's job: use `@click` and call the timeline yourself.

### Example

```vue
<script setup>
import * as a from "@freestylejs/ani-core";
import { rafTimeline } from "@freestylejs/ani-core";
import { useAniRef, useTimeline } from "@freestylejs/ani-vue";

const timeline = useTimeline(() =>
  rafTimeline(
    a.sequence([
      a.ani({ to: { translateX: 500, rotate: 360 }, duration: 1 }),
      a.ani({ to: { translateX: 0, rotate: 0 }, duration: 1 }),
    ])
  )
);

const { ref, style } = useAniRef(timeline, {
  initialValue: { translateX: 0, rotate: 0 },
});
</script>

<template>
  <div
    :ref="ref"
    :style="style"
    @click="timeline.play({ from: { translateX: 0, rotate: 0 } })"
  />
</template>
```

### Usage & Concepts

#### Lifecycle

-   **Function ref.** Use `:ref="ref"` and `:style="style"`. A component instance resolves to its `$el`. Setting the same element again does not add a binding; `null` unbinds.
-   **Initial style.** `style` is `createStyleSheet(initialValue, resolver)`, or `undefined` without an `initialValue`. It is the same object on every render, so a re-render never resets an animated style. It is rendered on the server; nothing subscribes to a clock during SSR.
-   **Timeline may be reactive.** `timeline` can be a timeline or a `Ref` of one. When it changes the element is rebound to the new one. Prefer `shallowRef`.
-   **Ownership.** The composable never disposes the timeline you pass. Create it with [`useTimeline`](/en/docs/vue/use-timeline) to dispose it with the component. On unmount the element is unbound.
-   **Resolver.** `resolver` shapes both the initial style and the frames (custom properties such as `--x` included).

#### When to Use

-   **Do** use `useAniRef` for high-frequency style animation of one element.
-   **Don't** use it when the template needs to read the animated values. Use [`useAni`](/en/docs/vue/use-ani) for that.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `timeline` | `RafTimeline<G> \| Ref<RafTimeline<G>>` | The timeline to bind. |
| `options.initialValue` | `AniGroup<G>` | (Optional) Rendered as the initial inline style. |
| `options.resolver` | `Resolver<Record<string, number>>` | (Optional) Custom style resolver. |

Returns `{ ref, style }`: `ref` is `(element: Element | ComponentPublicInstance | null) => void` and `style` is a `ComputedRef<StyleValue | undefined>`.
