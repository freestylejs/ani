### Quick Start: Your First Animation

This example uses React and the `useAniRef` hook for a high-performance animation that updates the DOM directly.

```tsx
import * as a from "@freestylejs/ani-core";
import { useAniRef, useTimeline } from "@freestylejs/ani-react";

const MyAnimatedComponent = () => {
  // 1. Define the animation's timeline. The component owns it.
  const myTimeline = useTimeline(() =>
    a.rafTimeline(
      // Animation structure.
      // >> move   to translateX: 500
      // >> return to translateX: 0
      a.sequence([
        a.ani({ to: { translateX: 500 }, duration: 0.8 }),
        a.ani({ to: { translateX: 0 }, duration: 1.2 }),
      ]),
    )
  );

  // 2. Connect the timeline to an element.
  const { ref, style } = useAniRef(myTimeline, {
    initialValue: { translateX: 0 }, // Set the initial animation value.
  });

  return (
    <>

      {/* 3. Attach the ref and the initial style to your element. */}
      <div
        ref={ref}
        style={style}
        className="h-20 w-20 rounded-lg bg-blue-500"
      />

      {/* 4. Use the timeline to play the animation. */}
      <button
        onClick={() => myTimeline.play({ from: { translateX: 0 } })}
      >
        Play
      </button>

    </>
  );
};

export default MyAnimatedComponent;
```

<Step>
### Define a structure

You define an animation's structure using **composition nodes** like `sequence`, `parallel`, and `ani`. This structure is a blueprint for the animation—it describes *what* should happen, but it doesn't hold any live values.

```ts
import * as a from "@freestylejs/ani-core";

// This structure is a reusable blueprint.
const myAnimation = a.sequence([
  a.ani({ to: { translateX: 500 }, duration: 0.8 }),
  a.ani({ to: { translateX: 0 }, duration: 1.2 }),
]);
```

Every duration, delay and offset is in **seconds**.
</Step>
<Step>
### Create a timeline

The **timeline** is the engine that runs your animation structure. Create a [`rafTimeline`](/en/docs/core-api/dynamic_timeline) from your structure, and it gives you a controller to manage playback. Use a [`waapiTimeline`](/en/docs/core-api/timeline) instead when the browser's native engine should run the animation.

```ts
import * as a from "@freestylejs/ani-core";

const myAnimation = a.sequence([
  a.ani({ to: { translateX: 500 }, duration: 0.8 }),
  a.ani({ to: { translateX: 0 }, duration: 1.2 }),
]);

// The timeline is the controller for the blueprint.
const myTimeline = a.rafTimeline(myAnimation);
```
</Step>
<Step>
### Connect to the UI and play

Use a framework-specific primitive (like `useAniRef` for React) to connect the timeline to a DOM element. Call the timeline's `play` method to start the animation, with a `from` value for the starting point.

```tsx
import * as a from "@freestylejs/ani-core";
import { useAniRef, useTimeline } from "@freestylejs/ani-react";

export function Box() {
  const myTimeline = useTimeline(() =>
    a.rafTimeline(a.ani({ to: { translateX: 500 }, duration: 0.8 }))
  );

  // Connect the timeline to an element...
  const { ref, style } = useAniRef(myTimeline, { initialValue: { translateX: 0 } });

  // ...and play it on demand.
  return (
    <div
      ref={ref}
      style={style}
      onClick={() => myTimeline.play({ from: { translateX: 0 } })}
    />
  );
}
```
</Step>
</Steps>

## Ownership

-   You create timelines, so you own them. Call `timeline.dispose()` when their owner goes away, or create them with `useTimeline` (`createTimeline`) so the component disposes them. The bindings only **detach** from timelines you pass in.
-   Bindings that create their own state machine (`useAniStates`, `createAniStates`) or follower (`useFollow`, `createFollow`) dispose it automatically.
-   Property names such as `translateX`, `rotate`, `scale` and `opacity` map to CSS (see [styles](/en/docs/core-api/advanced/building-bindings)). A name like `x` is not a CSS property: it is written as a style key `x`.

## Reduced motion

Animations honor the operating system's **reduce motion** setting by default: a timeline jumps to its end state instead of animating. Mark essential motion with `reducedMotion: 'ignore'`. See [Reduced motion](/en/docs/guides/reduced-motion).
