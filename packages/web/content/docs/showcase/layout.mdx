---
title: Layout Showcase
description: Fifteen live layout examples built on @freestylejs/ani-react/layout - switches, tabs, lists, drag to reorder, shared elements, presence and anchors.
---

Each example below is plain React with the public `@freestylejs/ani-react/layout` API:
elements marked with `useLayout`, `LayoutGroup`, and `AnimatePresence` with `usePresence`.
There are no capture or flush calls. Interrupt any of them mid-flight: every element continues
from where it is drawn, with the speed it had. Open **Code** under an example for the pattern
it uses. The [Layout guide](/en/docs/guides/layout) explains the API.

Native-quality layout motions use explicit physical springs (`type: 'spring'`). Finite timing
curves remain for separate presence choreography. The browser tests drive these same components
on a manual clock and compare marked boxes with an independent motion model, including changes
made mid-flight. Results are reported per engine; an unavailable run is not a pass. DOM geometry
and browser callback cadence do not certify physical iOS display or touch latency.

**Essentials**

- **Switch.** Flexbox moves the knob; `useLayout()` on the knob draws the move.
- **Tabs.** One underline with `layoutId`, rendered under the selected tab.
- **Smooth tabs.** A highlight pill with `layoutId` follows the pointer; shared-element radius correction is on by default.
- **Accordion.** The card resizes by layout and reveals its body; header and body use
  `layout: 'position'` so their text never stretches.

**Lists**

- **Shuffle.** Reorder the array; every tile moves from where it is drawn.
- **Drag to reorder.** `useLayoutDrive()` takes the row, moves its held origin 1:1, and releases
  it with the gesture's velocity into its latest slot. The gesture layer owns pointer identity,
  capture, cancellation and keyboard reorder; layout is the only position writer.
- **To-do list.** Add, tick and remove under `AnimatePresence mode="popLayout"`.
- **Stacked notifications.** A collapsed stack that fans out into a list.
- **E5 Notifications.** `useLayout` and `usePresence` share each toast; a removed toast exits
  in place while its siblings close the gap from the first frame.

**Shared elements**

- **E2 Create Button.** A button opens into a menu through shared `layoutId`s on the surface,
  label and icon; the label keeps its glyph size with `layout: 'position'`.
- **Family-style dialog.** A bottom sheet whose height follows its step, with steps swapped
  under `popLayout`.
- **E3 iOS Folder.** The closed icon and open panel are one shared, radius-aware surface; four
  nested shared tiles morph inside it, while the five staggered items are position-only layout
  participants so the surface can scale without stretching them.
- **E4 App Store.** A card opens into a detail view through three nested ids: surface, image
  and title.
- **Gallery.** Sixteen radius-aware tiles switch between a grid and a list; any tile opens a
  detail view that shares its `layoutId` and keeps the handoff's corners stable.

**Precision**

- **E1 Layout Anchor.** A child anchored with `layoutAnchor: { x: 0.5, y: 0.5 }` stays centred
  on its growing parent at every frame, and keeps its size until its own delay has passed.
