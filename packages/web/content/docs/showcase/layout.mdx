---
title: Layout Showcase
description: A reduced 2D layout lab for anchors, shared identity, presence and gallery poses.
---

Ani compiles measured DOM changes into compositor-native transforms. This lab
keeps the surface small enough to inspect: resize an anchored surface, hand off a
shared identity, open a folder, move a product card, stack notifications and
change a gallery pose. Every demo is live and uses the public
`@freestylejs/ani-react/layout` API.

The scope is the bounded 2D contract: depth-1 projection, shared `layoutId`,
`popLayout` presence and a reduced gallery. Full 3D/drag/scroll-observer rows are
explicitly out of scope.
