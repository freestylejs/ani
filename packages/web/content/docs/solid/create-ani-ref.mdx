---
title: createAniRef
description: A performant primitive that directly animates a DOM element via a ref, bypassing reactive updates.
---

This primitive animates CSS properties without a render per frame. It binds the element to a timeline through core (`timeline.bind`), which writes only the declarations that changed.

### Example

```tsx
import * as a from "@freestylejs/ani-core";
import { rafTimeline } from "@freestylejs/ani-core";
import { createAniRef, createTimeline } from "@freestylejs/ani-solid";

const InteractiveBox = () => {
  // 1. Create the timeline; createTimeline disposes it with the component.
  const timeline = createTimeline(() =>
    rafTimeline(a.ani({ to: { translateX: 500, rotate: 360 }, duration: 2 }))
  );

  // 2. Bind an element. `style()` is the initial inline style (also on the server).
  const { ref, style } = createAniRef(timeline, {
    initialValue: { translateX: 0, rotate: 0 },
  });

  // 3. The component renders once. The animation is written directly to the DOM.
  return (
    <>
      <button onClick={() => timeline.play({ from: { translateX: 0, rotate: 0 } })}>
        Play
      </button>
      <div ref={ref} style={style()} />
    </>
  );
};
```

### Usage & Concepts

#### Overview

`createAniRef` returns `{ ref, style }`. Solid calls `ref` once with the element; the element is then bound with `timeline.bind(element)`. Values are converted to CSS by the engine (see [styles](/en/docs/core-api/advanced/building-bindings)); custom properties (`--x`) returned by a `resolver` are written with `setProperty`.

`style()` is the inline style of `initialValue`, computed with `createStyleSheet`, with kebab-case keys as Solid expects (`border-radius`). It is plain data, so it renders on the server, and it never changes while the element animates.

#### Lifecycle

-   **Late refs.** A ref that is attached later (for example inside `Show`) is written with the current value at once.
-   **Swaps.** `timeline` may be an accessor. When it changes, the element is rebound to the new timeline and written with its value.
-   **Cleanup.** The binding is released with `onCleanup` of the owner that called `ref`. The written styles are kept.
-   **Ownership.** The primitive never disposes the timeline you pass. Create it with [`createTimeline`](/en/docs/solid/create-timeline) or dispose it yourself.
-   **Events.** DOM events are the framework's job: use `onClick` and friends and call `timeline.play(...)`.

#### When to Use

-   **Do** use `createAniRef` for animating CSS properties like `transform` and `opacity`.
-   **Don't** use it if you need the animated value to render text or pass it to a prop. Use [`createAni`](/en/docs/solid/create-ani) for that.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `timeline` | `RafTimeline<G> \| Accessor<RafTimeline<G>>` | Timeline to bind, or an accessor of one. |
| `options.initialValue` | `AniGroup<G>` | (Optional) Value of the initial `style()`. |
| `options.resolver` | `Resolver<Record<string, number>>` | (Optional) Maps values to style declarations, for `style()` and the writes. |

Returns `{ ref, style }`: `ref(element)` binds the element and `style()` is the initial inline style (or `undefined` without `initialValue`).
