---
title: createAniStates
description: A primitive for managing and transitioning between multiple animation states.
---

This primitive wraps the core `createStates` function. It is designed for components with multiple, distinct visual states (e.g., idle, hover, active). The element follows the machine across every transition.

### Example

```tsx
import * as a from "@freestylejs/ani-core";
import { createAniStates } from "@freestylejs/ani-solid";

const StateButton = () => {
  const { ref, style, state, transitionTo } = createAniStates({
    initial: "idle",
    initialValue: { scale: 1, opacity: 0.7 },
    states: {
      idle: a.ani({ to: { scale: 1, opacity: 0.7 }, duration: 0.5 }),
      hover: a.ani({ to: { scale: 1.1, opacity: 1 }, duration: 0.3 }),
    },
  });

  return (
    <button
      ref={ref}
      style={style()}
      onMouseEnter={() => transitionTo("hover")}
      onMouseLeave={() => transitionTo("idle")}
      data-state={state()}
    >
      Hover Me
    </button>
  );
};
```

### Usage & Concepts

#### Overview

`createAniStates` manages the active animation state and its timeline. When you call `transitionTo`, the current value (and velocity) is the starting point for the next animation, so transitions are smooth and interruptible. The element is bound through the machine (`machine.bind`), so it keeps following when the timeline is swapped.

#### Lifecycle

-   **Owns its machine.** The primitive creates the state machine and **disposes it when its owner is disposed**, which stops any running timeline (even `repeat: Infinity`). Later `transitionTo` calls resolve `'disposed'`.
-   **Config is read once**, at setup.
-   **Atomic transitions.** An unknown state throws a `RangeError` and changes nothing. `state()` mirrors the machine, including transitions started through `machine.transitionTo` and ignoring skipped ones.
-   **SSR.** `style()` is the inline style of `initialValue`; nothing subscribes to a clock until a transition.
-   **Events.** DOM events are the framework's job.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `config` | `StateProps` | `initial`, `initialValue`, `states` and optional `clock`. See [createStates](/en/docs/core-api/states). |
| `config.resolver` | `Resolver<Record<string, number>>` | (Optional) Maps values to style declarations. |

Returns `{ ref, style, state, transitionTo, machine }`.

| Member | Description |
| :--- | :--- |
| `ref` | Ref callback to attach to the element. |
| `style()` | Initial inline style of `initialValue` (kebab-case keys). |
| `state()` | Accessor of the current state name. |
| `transitionTo(name, config?)` | Switches state. Returns the run's `Promise<RunResult>`. |
| `machine` | The core `StateController` (`timeline()`, `value`, `onTransition`, `dispose()`, ...). |
