---
title: useAniStates
description: A hook that owns a state machine, animates an element between its states and re-renders on transitions.
---

`useAniStates` wraps the core `createStates`. It is for components with a few distinct visual states (idle, hover, active). The machine writes the element through `machine.bind`, and `state` re-renders the component once per transition.

### Example

```tsx
import { a } from "@freestylejs/ani-core";
import { useAniStates } from "@freestylejs/ani-react";

const StateButton = () => {
  const { ref, style, state, transitionTo } = useAniStates({
    initial: "idle",
    initialValue: { opacity: 0.7, scale: 1 },
    states: {
      idle: a.ani({ to: { scale: 1, opacity: 0.7 }, duration: 0.5 }),
      hover: a.ani({ to: { scale: 1.25, opacity: 1 }, duration: 0.4 }),
    },
  });

  return (
    <button
      ref={ref}
      style={style}
      data-state={state}
      onMouseEnter={() => transitionTo("hover")}
      onMouseLeave={() => transitionTo("idle")}
    >
      Hover Me
    </button>
  );
};
```

### Lifecycle

-   **Owns its machine.** The hook creates it and **disposes it on unmount**, which stops any running timeline. In `StrictMode` the machine is re-created for the second mount.
-   **Props are read once.** `states`, `initial`, `initialValue` and `clock` are read on the first render only, like the initial value of `useState`. To start from different props, remount with a `key`.
-   **Rendering.** `state` is the machine's state and re-renders on transitions, also on transitions made directly on `machine`. Frames never render.
-   **Stable `transitionTo`.** It keeps its identity across renders and returns the promise of the run (`'ended'`, `'interrupted'`, ...). An unknown state throws a `RangeError` and changes nothing. After unmount it resolves `'disposed'`.
-   **Stable `ref`.** Attaching an element binds it to the machine and writes the current value. The binding follows every later timeline.
-   **Server rendering.** `style` is built from `initialValue` and rendered into the HTML. Nothing subscribes.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `config` | `StateProps & { resolver? }` | `initial`, `initialValue`, `states`, optional `clock`, optional style `resolver`. See [createStates](/en/docs/core-api/states). |

Returns:

| Member | Description |
| :--- | :--- |
| `ref` | Element ref. |
| `style` | The initial inline style. |
| `state` | The current state name. |
| `transitionTo(name, config?)` | Switches state. |
| `machine` | The core `StateController`. Stable for the life of the component, except that StrictMode re-creates it once in development. |
