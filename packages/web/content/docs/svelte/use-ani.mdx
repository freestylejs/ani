---
title: useAni
description: A Svelte utility that creates a reactive store to track the state of an animation timeline.
---

This primitive subscribes to a `timeline`'s state and exposes it as a readable Svelte store. It's ideal when animated values need to be used within your component's markup or other reactive computations.

### Example

```svelte
<script>
  import { onMount } from 'svelte';
  import * as a from "@freestylejs/ani-core";
  import { rafTimeline } from "@freestylejs/ani-core";
  import { useAni, useTimeline } from '@freestylejs/ani-svelte';

  // 1. Create the timeline. The component owns it.
  const myTimeline = useTimeline(() =>
    rafTimeline(
      a.ani({ to: { count: 100 }, duration: 5, timing: a.timing.linear() })
    )
  );

  // 2. Get the readable store (and the timeline back).
  const [value] = useAni(myTimeline, { count: 0 });

  // 3. Play the animation on component mount.
  onMount(() => {
      myTimeline.play({ from: { count: 0 } });
  })
</script>

<div>
  <!-- 4. The animated value is read from the store via auto-subscription. -->
  <h1>Counter: {Math.round($value.count)}</h1>
  <button on:click={() => myTimeline.play({ from: { count: 0 } })}>
    Start
  </button>
</div>
```

### Usage & Concepts

#### Overview

The `useAni` primitive acts as a bridge between the `@freestylejs/ani-core` engine and Svelte's reactivity model. It takes a `timeline` instance and an `initialValue`, returning a readable Svelte store that updates on every animation frame, along with the timeline. You can auto-subscribe to the store's value using the `$` prefix.

#### Behavior

-   `timeline` may be a timeline or a `Readable` of one. Swaps are followed while the store has subscribers.
-   The store subscribes to the timeline only while it has subscribers, so nothing is retained otherwise (also on the server).
-   The returned timeline is the one you passed (the current one, for a store). The timeline you pass is never disposed; create it with [`useTimeline`](/en/docs/svelte/use-timeline) if the component owns it.

#### When to Use

-   **Do** use `useAni` when you need the animated values to be part of Svelte's reactive system.
-   **Do** use it for animations that affect text content, attributes, or props.
-   **Don't** use `useAni` for high-frequency style updates on a single element. For that, `useAniRef` is a better choice.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `timeline` | `RafTimeline<G> \| Readable<RafTimeline<G>>` | The timeline to read. |
| `initialValue` | `AniGroup<G>` | Value before the timeline has one. |

Returns `readonly [store, timeline]`: a `Readable<AniGroup<G>>` and the timeline.

### Related Components

-   [`useTimeline`](/en/docs/svelte/use-timeline) - Creates and disposes the timeline.
-   [`useAniRef`](/en/docs/svelte/use-ani-ref) - For performance-critical animations that write directly to the DOM.
