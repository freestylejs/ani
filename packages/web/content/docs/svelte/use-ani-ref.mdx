---
title: useAniRef
description: A Svelte action that binds a timeline directly to a DOM element, with a server-rendered initial style.
---

This primitive writes animation styles directly to a DOM element using the `use:` directive, bypassing Svelte's reactivity (no render per frame). The writes are done by core's `timeline.bind`; DOM events are Svelte's job (`on:click`, `onclick`).

### Example

```svelte
<script>
  import * as a from '@freestylejs/ani-core';
  import { rafTimeline } from '@freestylejs/ani-core';
  import { useAniRef, useTimeline } from '@freestylejs/ani-svelte';

  // 1. The component owns the timeline.
  const timeline = useTimeline(() =>
    rafTimeline(
      a.sequence([
        a.ani({ to: { translateX: 500, rotate: 360 }, duration: 1 }),
        a.ani({ to: { translateX: 0, rotate: 0 }, duration: 1 }),
      ])
    )
  );

  // 2. Get the action and the initial inline style.
  const { action, style } = useAniRef(timeline, {
    initialValue: { translateX: 0, rotate: 0 },
  });
</script>

<!-- 3. Bind the action to the element. `style` is also rendered on the server. -->
<div
  use:action
  {style}
  on:click={() => timeline.play({ from: { translateX: 0, rotate: 0 } })}
/>
```

### Usage & Concepts

#### Overview

`useAniRef(timeline, options?)` returns `{ action, style }`. `style` is a CSS declaration string made from `initialValue` (for example `"transform: translateX(0px) rotate(0deg)"`), so server-rendered markup starts in the right place. It is `undefined` without `initialValue`. Nothing subscribes to a clock or touches the DOM during server rendering.

#### Lifecycle

-   **Bind on mount.** The action calls `timeline.bind(node)`: a timeline that already has a value is written at once, then every frame, changed declarations only.
-   **Unbind on destroy.** `destroy()` stops the writes and keeps the styles that were written.
-   **Timeline may be a store.** `timeline` can be a timeline or a `Readable` of one. Swaps are followed: every mounted node is rebound to the new timeline and the replaced one writes nothing any more.
-   **One action, many nodes.** The returned action can be applied to several nodes; each keeps its own binding.
-   **Resolver.** `options.resolver` shapes both the `style` string and the writes (custom properties such as `--x` included).
-   **Ownership.** The action never disposes the timeline you pass. Use [`useTimeline`](/en/docs/svelte/use-timeline) to create it.
-   **Events.** There is no `events` option. Attach handlers with Svelte (`on:click`) and call the timeline.

#### When to Use

-   **Do** use `useAniRef` for high-performance animations of CSS properties like `transform` and `opacity`.
-   **Don't** use `useAniRef` when you need to read the animated values elsewhere in your component. Use `useAni` for that.
-   For a list of elements driven by one plan, use [`useAniGroup`](/en/docs/svelte/use-ani-group).

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `timeline` | `RafTimeline<G> \| Readable<RafTimeline<G>>` | The timeline to bind. |
| `options.initialValue` | `AniGroup<G>` | (Optional) Rendered as the initial `style` string. |
| `options.resolver` | `Resolver<Record<string, number>>` | (Optional) Maps values to style declarations. |

Returns `{ action: Action<HTMLElement>, style: string | undefined }`.
