---
title: useAniStates
description: A primitive for managing and transitioning between multiple animation states on an element.
---

This primitive is a Svelte-specific wrapper around the core `createStates` function. It's designed for components with multiple, distinct visual states (e.g., idle, hover, active) and provides a simple API to manage transitions between them.

### Example

```svelte
<script>
  import { a } from "@freestylejs/ani-core";
  import { useAniStates } from "@freestylejs/ani-svelte";

  const { action, style, state, transitionTo } = useAniStates({
    initial: "idle",
    initialValue: { scale: 1, opacity: 0.7 },
    states: {
      idle: a.ani({ to: { scale: 1, opacity: 0.7 }, duration: 0.5 }),
      hover: a.ani({ to: { scale: 1.1, opacity: 1 }, duration: 0.3 }),
    },
  });
</script>

<button
  use:action
  {style}
  on:mouseenter={() => transitionTo("hover")}
  on:mouseleave={() => transitionTo("idle")}
  data-state={$state}
>
  Hover Me
</button>
```

### Usage & Concepts

#### Overview

The primitive manages the active animation state and its timeline, handling seamless transitions. When you call `transitionTo`, the current value and velocity are the starting point of the next animation, so effects stay smooth and interruptible. The action binds the machine (`machine.bind`), so it follows every timeline swap.

#### Lifecycle

-   **Owned.** The machine is created by the primitive and disposed when the component is destroyed, which stops any running timeline (even `repeat: Infinity`). After that `transitionTo` resolves `'disposed'`.
-   **Action.** Binds on mount (the current value is written at once) and unbinds on destroy; it never disposes the machine.
-   **Server rendering.** `style` is the CSS declaration string of `initialValue` (or the 1.x `initialFrom`). Nothing starts on the clock while rendering on the server.
-   **Atomic.** `transitionTo` validates first (an unknown state throws a `RangeError` and nothing changes). The `state` store mirrors the machine, also for a direct `machine.transitionTo`.
-   **Resolver.** `resolver` shapes both the `style` string and the writes.

#### When to Use

-   **Do** use `useAniStates` for components with a finite number of visual states, such as buttons, interactive cards, or navigation items.
-   **Don't** use it for animations that are not state based. Use [`useAniRef`](/en/docs/svelte/use-ani-ref) with your own timeline.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `config` | `StateProps & { resolver? }` | `initial`, `initialValue`, `states`, optional `clock` and `resolver`. See [createStates](/en/docs/core-api/states). |

Returns `{ action, style, state, transitionTo, machine }`.

| Member | Description |
| :--- | :--- |
| `action` | Svelte action to put on the element (`use:action`). |
| `style` | Initial inline style string. |
| `state` | Readable store of the current state name. |
| `transitionTo(name, config?, canBeIntercepted?)` | Switches state. Resolves with how the run ended. |
| `machine` | The state controller (`timeline()`, `value`, `onTransition`, ...). |
