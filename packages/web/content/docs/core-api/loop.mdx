title: loop
description: A composition node that repeats a child animation a specified number of times.
---

A `loop` node is a composition that repeats a single child animation node a set number of times, one after another.

### Example

```typescript
import { a } from "@freestylejs/ani-core";

// 1. Define an animation that pulses an element's scale.
const pulse = a.sequence([
    a.ani({ to: { scale: 1.2 }, duration: 0.5 }),
    a.ani({ to: { scale: 1 }, duration: 0.5 }),
]);

// 2. Create a loop to repeat the pulse animation 3 times.
const loopedPulse = a.loop(pulse, 3);

// 3. Create and play the timeline.
const myTimeline = a.dynamicTimeline(loopedPulse);
myTimeline.play({ from: { scale: 1 } });
```

### Usage & Concepts

#### Overview

`loop` is a composition node that takes a single child animation and repeats it a set number of times. The total duration of the `loop` node is the duration of its child multiplied by the loop count. This is a convenient alternative to manually creating a long `sequence` of identical animations.

An optional third `timing` argument applies a timing function to the looped child segments (only where the child does not define its own timing):

```typescript
// Loop with an ease applied to every repetition.
const easedLoop = a.loop(pulse, 3, a.timing.ease());
```

#### Validation

`loopCount` must be a finite integer `>= 0`. Anything else (including `Infinity`) throws a `RangeError`, because the tree is flattened into a plan and an unbounded plan can not be built. Use the `repeat: Infinity` option of [`play()`](/en/docs/core-api/dynamic_timeline) for endless playback.

#### Best Practices

-   **Do** use `loop` for simple, repetitive animations like pulsing or bouncing.
-   **Don't** use `loop` for endless animations. Use `repeat: Infinity` in `play()`, which does not grow the plan.
-   **Don't** use very large counts. Each repetition adds segments to the plan; per-frame cost does not grow, but the plan build does.

### API Reference

| Name | Type | Description |
| :--- | :--- | :--- |
| `child` | `AnimationNode<G>` | The node to repeat. |
| `loopCount` | `number` | Finite integer `>= 0`. |
| `timing` | `TimingFunction` | (Optional) Applied to child segments without their own timing. |
| `id` | `string` | (Optional) Identifier of the node. |

### Related Components

-   [`dynamicTimeline`](/en/docs/core-api/dynamic_timeline) - The `play` method's `repeat` option provides an alternative way to loop.
-   [`sequence`](/en/docs/core-api/sequence) - Can be used to manually create loops, though `loop` is more concise.
