# Reference visual assets

`exposure-reference.png` contains ONLY the city photograph region (333×200 pixels) from Motion's publicly advertised exposure-slider poster, not any interface, number, pointer, ruler, or interaction. Source observed 2026-11-04:
https://images.motion.dev/examples/stage/react/carousel-ios-exposure-slider/v-a4885d84d9b7/thumb.webp

It is a lower-resolution preview-derived visual asset for this local comparison lab. The interactive UI and brightness/ruler behavior are live Ani code. `IosExposureSlider.imageSrc` accepts replacement production artwork. This preview crop is not a claim of access to the original photograph/source asset or a grant to redistribute it commercially. Reference artwork remains credited to Motion/their credited creators.

Other components use publicly linked Motion App Store images and Apple Creator Studio icons by URL. They are replaceable through component data props; none is an executable dependency or a screenshot-based imitation of a component.
